# Secure Password Generator

A modern and secure password generator built with Python and Tkinter. This application helps users create strong passwords with customizable options, including password length, uppercase and lowercase letters, numbers, and special symbols. It uses cryptographically secure randomness to ensure maximum security and includes a password strength indicator and clipboard support for convenience.

## Features

- Generate secure passwords using cryptographically secure randomness
- Adjustable password length
- Include or exclude:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special symbols
- Password strength indicator (Weak / Medium / Strong)
- One-click copy to clipboard
- Simple and user-friendly graphical interface
- Reset button to clear all fields

## Technologies Used

- Python
- Tkinter
- Secrets

## Installation

1. Clone the repository:

```bash
git clone https://github.com/ILATRACHE/Secure-Password-Generator.git
```

2. Navigate to the project folder:

```bash
cd Secure-Password-Generator
```

3. Run the application:

```bash
python main.py
```
